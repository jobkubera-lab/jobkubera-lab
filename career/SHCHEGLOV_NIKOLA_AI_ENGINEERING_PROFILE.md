# HOW I WORK

I work from:

**problem → architecture → implementation → test → review → GitHub evidence**

For AI systems I separate responsibilities instead of relying on one model for every decision:

- **Builder** creates the result.
- **Critic** challenges assumptions and identifies weaknesses.
- **Verifier** checks required conditions independently.
- **Private/local workers** can handle sensitive context.
- **External models** receive only allowed context.
- **Human owner** retains authority over consequential actions.
