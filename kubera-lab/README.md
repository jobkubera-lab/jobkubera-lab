# KUBERA LAB

**Technology intelligence, practical AI, local tools and digital independence.**

KUBERA LAB is a portfolio project by Nikola Kubera. It presents practical experiments and working concepts across AI agents, migration technology, civic maps, local AI, privacy, automation and open-source research.

## Why this project exists

Many AI portfolios show isolated prompts or copied demos. KUBERA LAB is designed as a small technology laboratory: each idea starts with a real human problem, is tested with accessible tools and is documented as a reusable product concept.

## Core areas

- **AI Agents** — assistants for research, documents, customer support and workflow coordination.
- **Migration Technology** — practical tools for document organisation, relocation and new-arrival guidance.
- **Local AI** — private, self-hosted language models and knowledge bases.
- **Civic Technology** — community maps and local-service discovery.
- **Technology Intelligence** — structured evaluation of new open-source tools.
- **Prompt Engineering** — tested prompt systems, quality control and reusable workflows.
- **Automation** — practical process design using APIs, n8n, Flowise and Python.
- **Digital Resilience** — privacy, backups, account recovery and continuity planning.

## Featured projects

### Mitcham Survival Map
A community-oriented interactive map for residents and new arrivals in Mitcham. It combines useful places, local services, sport, recycling and practical navigation.

### Kubera Local AI
A starter architecture for running local language models, private document search and AI assistants on affordable hardware.

### Kubera Migration Toolkit
Templates, checklists and AI-assisted workflows for organising migration and employment cases.

### Kubera Technology Radar
A structured system for rating technologies by usefulness, privacy, cost, maturity, business value and open-source status.
