# Creative Object DNA

**Status:** `CONCEPT`  
**Layer:** Reality / Digital Objects

## Purpose
Give a physical or creative object a durable digital identity across research, media creation, publishing and commerce workflows.

## Object DNA fields
- stable object ID;
- title / type / origin;
- known facts and sources;
- image references;
- condition / physical notes where appropriate;
- prompts and generated-media lineage;
- captions / campaigns;
- publication history;
- market/research links;
- rights and provenance notes.

## Example application
A collectible object can connect its original photographs to research, a Sora/video prompt, an Instagram publication and later marketplace research without mixing different objects together.

## Integrations
Reality Graph, Prompt Evolution Engine, Project Memory, Public/Private Twin.

## MVP
Define `object-dna.yaml` and use it for a small curated collection.
