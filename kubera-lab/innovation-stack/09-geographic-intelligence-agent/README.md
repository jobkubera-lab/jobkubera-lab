# KUBERA Geographic Intelligence Agent

**Status:** `CONCEPT`  
**Layer:** Application

## Purpose
Answer practical location questions using structured local knowledge rather than generic text generation alone.

## Possible questions
- Which useful services are near a location?
- What places match specific categories or access constraints?
- What is known from first-hand observations versus external sources?
- Which map layer should be displayed for a newcomer or visitor?

## Data sources
GeoMemory, City DNA, community maps, approved public map APIs and verified web research.

## Output
Answer + map-ready coordinates/GeoJSON + provenance for each important claim.

## Safety
No claim of live opening hours, transport status or accessibility without a current source.

## Integrations
Kubera Guide, Mitcham/Merton mapping, GeoMemory Engine, Web Research, Evidence Ledger.
