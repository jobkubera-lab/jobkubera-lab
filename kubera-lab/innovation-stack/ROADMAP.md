# KUBERA Innovation Stack — Roadmap

## Phase 1 — Specification ✅
- Define the 18 modules.
- Give each module inputs, outputs, constraints and integrations.
- Publish a module registry and architecture map.

## Phase 2 — Shared schemas
- Define common IDs for projects, places, evidence, failures, agents and skills.
- Add JSON Schema / YAML examples.
- Connect shared records to SQLite where persistence is required.

## Phase 3 — First executable core
Priority implementation order:
1. Personal AI Constitution
2. Human Authority Budget
3. Reality Graph
4. Failure Vaccine
5. Agent Reputation Engine
6. Proof-of-Work Portfolio

## Phase 4 — Real tools
- Filesystem adapter
- Git/GitHub adapter
- Web research adapter
- Map / GeoJSON adapter
- Document/PDF adapter
- Controlled automation adapter

## Phase 5 — Applications
- Geographic Intelligence Agent using Kubera Guide / community-map data.
- British English Personal Language Agent.
- Creative Object DNA for collection / media workflows.

## Phase 6 — Automated public layer
- Public/Private Twin generator.
- Living README.
- GitHub Guardian.
- Proof-of-Work dashboards.

## Definition of done
A module becomes `ACTIVE` only when it has executable code, tests, documented inputs/outputs and a reproducible demonstration. Until then it remains `CONCEPT` or `PROTOTYPE`.
