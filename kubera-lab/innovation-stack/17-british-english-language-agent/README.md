# British English Personal Language Agent

**Status:** `CONCEPT`  
**Layer:** Application / Learning

## Purpose
Build an adaptive English-learning agent around actual communication needs instead of a generic course sequence.

## Learning record
- intended meaning;
- original phrase;
- natural British-English version;
- pronunciation / reductions;
- context and formality;
- recurring error tags;
- review date;
- confidence after practice.

## Example flow
```text
Real conversation need → phrase → correction → British natural form → pronunciation cue → spaced review
```

## Privacy
Private conversation examples should remain local unless deliberately anonymised for a public demo.

## Integrations
Project Memory, Reality Graph, Prompt Evolution Engine, local speech/TTS tools where available.

## MVP
A local SQLite phrase bank with spaced-review scheduling and a simple terminal/web interface.
