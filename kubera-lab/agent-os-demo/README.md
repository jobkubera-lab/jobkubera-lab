# KUBERA Agent OS demo

Prototype browser demo for the customer flow.

1. Download or clone this repository.
2. Open `kubera-lab/agent-os-demo/index.html` in a browser.
3. Choose one of the three demo jobs.
4. Edit the task text if needed.
5. Click `Prepare checked brief`.
6. Review the brief, sources, engineering score and draft action.
7. Click `Approve` only after the human has reviewed the result.
8. The page changes the local status to `approved: yes`.
9. The Approve button does not submit a form.
10. It does not send email.
11. It does not post to social media.
12. It does not call an API.
13. It does not make a network request.
14. `jobs.json` contains the three canned demo records.
15. Status: prototype, not a live council service or production eligibility system.
