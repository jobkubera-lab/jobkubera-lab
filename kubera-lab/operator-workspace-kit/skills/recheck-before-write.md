# Skill: Recheck Before Write

## Purpose
Не перезаписать свежие изменения и не сохранить работу поверх устаревшего состояния.

## Procedure

1. Непосредственно перед write/commit заново прочитай target file/repo state.
2. Сверь current revision/SHA/status с тем, от чего строился draft.
3. Если target изменился — останови слепую запись и пересобери diff.
4. Проверь scope: меняются только нужные файлы.
5. Просмотри diff перед commit/PR.
6. После записи снова fetch/open результат и убедись, что сохранилось именно ожидаемое.

## Pass condition
Финальная запись основана на свежем состоянии и подтверждена повторным чтением.

## Forbidden
Не делать force overwrite только потому, что более ранняя копия «должна быть актуальной».
