# KUBERA Local Desk

Канон. Если README, ChatGPT или новый модуль спорит с этим файлом — прав этот файл, не плоди третий бренд.

Обновлено: 2026-09-01.

## Одна фраза

Человек описывает задачу по жизни в районе. KUBERA находит официальный источник и готовит следующий шаг. Человек решает и действует.

## Что это не есть

- не чат-бот совета
- не решение о пособии или визе
- не автопостинг в X
- не 18 отдельных стартапов

## Кто пользователь

1. Житель / новоприбывший в Merton–Mitcham (и соседние районы).
2. Сотрудник стойки: библиотека, advice, приём.
3. Вы сами — как оператор, который проверяет источники.

Коммерческий контур виз и работы (Kubera Job) живёт рядом, на другом входе. На кнопке совета его нет.

## Три рабочих куска (уже есть)

1. **Lookup** — Civic Evidence OS. Каталог Merton, fallback, safety, профиль по согласию, режим для сотрудника.
2. **Place** — Mitcham map + Community Compass. Карта и вручную проверенные события.
3. **Control** — Agent Fabric / Trust Mesh. Агент готовит действие. Наружу — только после человека. Журнал без сырого вопроса.

Всё остальное в GitHub — библиотека или черновик.

## Как выглядит работа

```
вопрос
  → поиск только в проверенном каталоге
  → ответ: услуга + официальный URL + почему так
  → если неясно или опасно: отказ и контакт совета
  → сотрудник может показать тот же ответ простым текстом
  → форму отправляет человек, не программа
```

## Правила, которые нельзя ломать

- официальные URL только
- нет выдуманной услуги
- неоднозначность = fallback, не «лучший догад»
- профиль только с явным согласием, special-category теги запрещены кодом
- в журнал — хеш вопроса, не текст
- не писать «одобрено советом Merton»
