# UK Public-Service Open-Source Proposals

**Author:** SHCHEGLOV NIKOLA

This folder contains three submission-ready technical proposals for UK public-service open-source projects:

1. NHS.UK Frontend — multilingual and plain-language support patterns
2. GOV.UK Frontend — explicit processing/loading state guidance for forms
3. LocalGov Drupal — provider-neutral natural-language service discovery

## What is already public

A separate LocalGov Drupal contribution from this account is already live:

- https://github.com/localgovdrupal/localgov/issues/927 — `Feature request: language switcher for resident-facing service pages`

The natural-language service-finder proposal in this folder is a different idea and does not duplicate issue #927.

## External publication status

Publication was attempted through the connected GitHub integration for all three target repositories:

- `nhsuk/nhsuk-frontend`
- `alphagov/govuk-frontend`
- `localgovdrupal/localgov`

GitHub returned `403 Resource not accessible by integration` for each attempt. This is an integration-permission limitation, not a rejection by the NHS, GOV.UK or LocalGov project teams.

The proposals therefore remain ready for manual submission from the GitHub website under the same account.

## Why these drafts differ from the original research pack

The supplied source reports contained useful product ideas, but also included quantitative claims and implementation assumptions that were not supported by verifiable evidence or did not match the target repositories. Those claims were removed rather than published as fact.

Examples removed or corrected include unsupported percentages/cost-savings figures, React/Drupal implementation claims for NHS.UK Frontend, assumptions about GOV.UK validation behaviour, and vendor-specific AI pricing claims.
