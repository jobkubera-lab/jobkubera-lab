# External publication attempts

Author: **SHCHEGLOV NIKOLA**

This log records attempts to publish the prepared proposals to the target external repositories through the connected GitHub integration.

Target repositories:
- `nhsuk/nhsuk-frontend`
- `alphagov/govuk-frontend`
- `localgovdrupal/localgov`

If the integration lacks permission to create an issue in an external repository, GitHub may return `403 Resource not accessible by integration`. That is a connector permission limitation, not a rejection by the target project.
