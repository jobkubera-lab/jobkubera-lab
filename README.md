### DZAMBALA execution rule

```text
Task / Handoff
  → WorkContract
  → Privacy + Tool Validation
  → Source Gate → Evidence Gate → Action Gate
  → Signed Approval when required
  → Idempotent SovereignToolExecutor
  → Action Log → Evidence Ledger
  → Human-reviewed result
```

The public reference runtime is **v0.9.1**. The operator pack and `SovereignToolExecutor` are covered by the repository CI and keep external side effects behind one controlled execution choke point.
