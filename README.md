## KUBERA — AI work partner, human stays in control

Nikola / KUBERA builds practical AI and civic-tech prototypes around verified information and controlled action.  
The flagship is **Civic Evidence OS**: deterministic Merton service lookup with tests and conservative fallbacks.  
It returns official service links and evidence terms; it does **not** submit council forms.  
**Agent Fabric / Trust Mesh** explores approval, evidence-ledger and deterministic agent-control mechanics.  
**Community Compass v0.2** publishes manually verified event data with deterministic validation.  
These are engineering prototypes and research systems, not a council service.  
They do not make production eligibility decisions and do not claim council adoption.  
The design principle is simple: KUBERA prepares; the human remains the authority.

## Engineering focus

- **Civic tech** — explainable service discovery based on controlled data and official sources.
- **AI agents** — deterministic orchestration, verification, approval boundaries and evidence trails.
- **Privacy** — minimise retained resident data and keep consequential actions under human control.
- **Local intelligence** — turn verified local information into usable maps, lookups and decision support.

## Current boundaries

- Prototypes are not presented as production council systems.
- Civic Evidence OS does not determine official eligibility or submit forms.
- Community Compass event data is manually verified seed data, not an automatic live-event scraper.
- Reference agent code demonstrates control and evidence mechanics; it is not a production security boundary.
